## Como abrir la pagina:
Si descargaste el .zip o clonaste el repositorio:
* Descomprimir en una carpeta a gusto (si descargaste el .zip)
* abrir uno de los html (preferentemente index.html) en tu navegador de preferencia

Si estas conectado al repositorio:
* moverse a la carpeta raiz de proyecto
* click derecho a alguno de los html y abrir con el navegador integrado
* alternativamente puedes usar la extención live server si trabajas con VS code
